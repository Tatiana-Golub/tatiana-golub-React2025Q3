# React – State Management Task

Hey there! 👋

This is a React project I built for the [React 2025Q3 course](https://rs.school/).
This part is all about managing application state across components (not just local state).

Full task description:
🔗 [State Management Task](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/state-management.md)

---

## What’s done

- Introduced **global state** (via Context and Redux)
- Connected UI components to that global state
- Handled updates from multiple places (UI events)

---

## Tech & approach

- Employed **Redux** for state management solution
- Employed **Context API** for theme change
- Shared state for data that multiple components need
