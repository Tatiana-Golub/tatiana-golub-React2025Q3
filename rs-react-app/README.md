# Next.js – SSR / SSG Task

Hey! 👋

This is a React app I built for the [React 2025Q3 course](https://rs.school/).
The aim here was to use **Next.js** to build pages using **Server-Side Rendering (SSR)**.

You can see the full task here:
🔗 [Next.js SSR / SSG Task](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/nextjs-ssr-ssg.md)

---

## What I did

- Static requests are done from the server
- Added internationalization
- Links rendered via next-intl createNavigation function

---

## Tech & approach

- Next.js file-based routing
- Internationalization via next-intl
- next-intl createNavigation function
- Shared layout is used at the root of application
