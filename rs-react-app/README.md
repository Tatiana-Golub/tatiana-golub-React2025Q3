You can see the full task here:
🔗 [Queries Task](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/queries.md)

## What’s done

- Fetched data from external API using **RTK Query**
- Implemented **caching** so repeated queries don’t always refetch
- Handled loading states and error states clearly

---

## Tech & approach

- Implement RTK Query endpoints for all API calls
- Use RTK Query hooks in components
