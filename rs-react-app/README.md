# React – Hooks and Routing Task

Hey there! 👋

This is a React project I worked on for the [React 2025Q3 course](https://rs.school/).  
The goal was to create a **single-page application (SPA)** using **React Router** and **functional components** with **hooks**.

Check out the full task here:  
🔗 [Hooks and Routing Task](https://github.com/rolling-scopes-school/tasks/blob/master/react/modules/tasks/functional-routing.md)

---

## What’s done

- Built a **single-page application (SPA)** with multiple pages  
- Implemented **React Router** for navigation between pages  
- Used **functional components** and **React hooks** (`useState`, `useEffect`, `useParams`, `useNavigate`)  
- Created pages:  
  - Main Page
  - About  
  - Not Found (404)  
- Added **404 page** for unknown routes
